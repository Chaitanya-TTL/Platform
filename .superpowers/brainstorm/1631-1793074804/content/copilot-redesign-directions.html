A · Investigation workbench

Persistent case navigation, focused conversation, and a source panel that can be collapsed. The investigation—not the chat thread—is the organizing unit.

Best when: investigators repeatedly move between threads, graph context, and source records. Tradeoff: more workspace chrome to learn.

C · Graph-led investigation

The existing Lattice graph remains the primary canvas; Copilot becomes a contextual inspector for the selected node, relationship, or source.

Best when: questions start from exploring the graph. Tradeoff: long answers and multiple citations have limited room.
