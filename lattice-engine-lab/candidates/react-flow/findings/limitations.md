# React Flow baseline limitations

- DOM-backed rich nodes are excellent for detailed evidence but require realistic scale testing.
- Stable sector placement is intentionally deterministic and is not a general graph-layout engine.
- Collapsing shared neighborhoods is conservative to avoid removing focus-protected nodes.
- Client-side memory data depends on browser support and is not yet automated.
- Semantic accessibility is parallel to the canvas rather than intrinsic to every graph interaction.
- The spike does not evaluate server rendering, collaborative state, export, or production authorization.
