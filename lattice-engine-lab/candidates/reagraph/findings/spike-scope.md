# Reagraph High-Density Spatial Interaction Spike

This specialist experiment evaluates whether Reagraph earns a distinct High-Density Spatial Exploration Mode. It does not replace React Flow, Graphology, ELK, Relation Graph-inspired editing, or canonical Lattice truth.

The spike provides deterministic 50, 500, 1,000, and guarded 10,000-entity datasets; source and evidence semantics; Reagraph clustering; native edge aggregation; prioritized labels; search and focus; one-to-three-hop neighborhood isolation; a requirement-to-FI path; cluster isolation; multiple purposeful 2D layouts; camera focus-set restoration; reduced motion; lifecycle controls; and an accessible semantic representation.
