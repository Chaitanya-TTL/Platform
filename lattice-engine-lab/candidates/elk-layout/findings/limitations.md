# Limitations

- Main-thread bundled ELK is evaluated first; worker packaging is documented as a follow-up.
- Previous coordinates are measured but not yet passed as full ELK interactive-layout constraints.
- Approximate crossing counts do not account for shared endpoints or curved production rendering.
- The neutral SVG view is not a proposed Lattice user interface.
- Port and compound behavior must still be integrated with real React Flow node dimensions.
