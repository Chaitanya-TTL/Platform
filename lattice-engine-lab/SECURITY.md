# Security and quarantine policy

- Never place credentials, environment files, connector configuration, production payloads, tarballs, or production lockfiles in this lab.
- Package pins are provisional until registry metadata, publication date, advisories, peers, runtime requirements, lifecycle scripts, integrity, license, and dependency tree are reviewed.
- Initial candidate installs use lifecycle scripts disabled.
- Graphin must not be installed on the primary workstation.
- yFiles, Ogma, and KeyLines require approved trials. No proprietary package is included.
