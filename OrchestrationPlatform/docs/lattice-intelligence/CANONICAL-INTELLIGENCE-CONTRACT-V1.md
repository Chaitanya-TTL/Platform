# Canonical Engineering Intelligence Contract V1

`EngineeringIntelligenceInvestigation` version `1.0` is the graph-ready backend contract above `UnifiedProductIntelligence`. It separates subject, entities, relationships, evidence, findings, source representations, identity clusters, temporal context, and summary.

Entity and relationship kinds use registered string constants. Future domain kinds can be added without a source-specific Lattice architecture. Relationship families provide stable Lattice presentation semantics.

Sprint 2 maps intelligence already proven by the backend: unified subject, source representations, source status, provenance, artifact evidence, identity clustering, and backend findings. Later domain sprints can add requirements, changes, operations, cost, and configuration entities without changing the envelope.
