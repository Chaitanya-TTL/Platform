# Fact, Inference, and Finding Semantics

- A fact is represented directly by source evidence or explicit source status.
- An inference is a deterministic or confidence-scored relationship derived from evidence. It requires evidence IDs and confidence.
- A finding is a platform assertion from a named evaluator. It identifies affected entities, provenance, review state, and available evidence.
- Confidence is not a substitute for authority. Source facts do not receive artificial confidence values.
