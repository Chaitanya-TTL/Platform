# Lattice direct discovery architecture lock

Lattice has two first-class entry modes. `/lattice` opens Discovery Mode. `/lattice?handoff=<id>` resolves a contextual selection. Both converge into schema-version 3 canonical investigations and use the existing Graphology index, ELK layout adapter, React Flow renderer, selection model, and persistence boundary.

## Capability truth

- Teamcenter: exact Item ID discovery and pipeline structure extraction. No live name search is claimed.
- Windchill: live name/number search, structure, revisions, and change context.
- SAP: live material-catalog search, BOM extraction, and staged operational evidence with partial-success semantics.
- Configit: exact Product ID discovery and product solve. No live name search is claimed.
- Requirements: contextual evidence, never a permanent connector pillar.

## Runtime boundaries

`FederatedSearchOrchestrator` owns request IDs, per-source AbortControllers, stale-response protection, independent timeouts, partial completion, retry, and cancellation. Source adapters consume existing production routes and return normalized contracts. React components render snapshots only. Identity correspondence remains explicit and source-native identities are never erased.

Discovery resolves only the selected root structure. Revisions, changes, requirements, SAP operations, documents, and configuration evidence remain staged enrichment and cannot block the initial investigation.
